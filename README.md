# RoomRadar - Live Event Networking Identification App

RoomRadar is a real-time attendee discovery platform designed for mixers, summits, and campus networking events. It solves attendee identification by giving participants real-time visibility into who is currently in the room, their target interests, and their domain tags.

## Key Features
- **Instant Check-In:** Quick onboarding form capturing name, role, and networking goals.
- **Live Directory Feed:** Dynamic attendee list filtered by role badges (Tech, Design, Founders, Marketing).
- **Icebreaker Prompts:** Customized conversation starters on every card to simplify introductions.

## Tech Stack
- **Framework:** Next.js / React
- **Styling:** Tailwind CSS & Lucide Icons
- **Deployment Platform:** Vercel
